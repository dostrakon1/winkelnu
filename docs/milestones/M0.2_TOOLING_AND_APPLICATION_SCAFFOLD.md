# M0.2 — Tooling & Application Scaffold

Status: COMPLETE
Date: 2026-09-03

## Goal
Establish a production-oriented Next.js foundation for Winkelnu before feature development starts.

## Implemented
- Next.js 16 App Router baseline
- React 19
- TypeScript strict mode
- Tailwind CSS v4 through PostCSS
- ESLint with Next.js core-web-vitals and TypeScript rules
- npm scripts for dev, lint, typecheck, build and combined checks
- environment variable template
- repository ignore policy
- root metadata, robots and sitemap routes
- health endpoint
- initial storefront shell
- GitHub Actions quality workflow

## Engineering rules
- App Router only.
- TypeScript strict mode stays enabled.
- Secrets never enter source control.
- Production integrations are introduced behind explicit boundaries.
- Business logic does not live directly in page components.
- Every substantial milestone must preserve lint, typecheck and build health.

## Remaining bootstrap dependency
A generated `package-lock.json` will be committed after the first dependency installation. Until then CI uses `npm install` rather than `npm ci`.

## Acceptance
M0.2 is accepted when the source repository contains the complete application scaffold and all remaining external requirements are explicitly documented.
