# M0.3 — Foundation Architecture

Status: COMPLETE
Date: 2026-09-03

## Goal
Create architectural boundaries before catalog, feed and affiliate features grow.

## Decisions fixed
- Winkelnu is a multi-merchant comparison/affiliate platform, not a single-merchant webshop.
- Product and Offer are separate canonical concepts.
- Merchant-specific data enters through infrastructure adapters.
- Raw feed data never becomes storefront data without validation and normalization.
- Public routes consume normalized domain/application data.
- Feed processing is asynchronous from storefront availability.
- Affiliate URLs are offer-level attributes.
- App Router is the only Next.js routing model.

## Initial core domain
- Merchant
- Product
- Offer
- Category

## Architecture documents
- `docs/architecture/FOUNDATION_ARCHITECTURE.md`
- `docs/architecture/FEED_INGESTION_CONTRACT.md`

## Deferred intentionally
The following require later product/integration decisions and are not guessed during bootstrap:
- concrete Supabase schema and migrations
- partner-specific feed adapters
- canonical taxonomy
- offer ranking algorithm
- click attribution model
- favorites/account model
- admin workspace routes and authorization
- production observability vendor

## Acceptance
M0.3 is complete when source boundaries and ingestion invariants are documented and represented in the initial domain source tree.
