# M0.22 — Production Import Composition & Authenticated Operations Trigger

Status: repository-side implemented; CI verification pending.

## Delivered
- production composition service connecting registry resolution, partner adapter resolution and `importFeed`;
- Supabase-backed production worker factory;
- production factory refuses non-Supabase persistence;
- Daisycon JSON adapter registered in production composition;
- authenticated POST-only operations route;
- constant-time bearer-secret verification;
- server-only `WINKELNU_IMPORT_TRIGGER_SECRET` contract;
- request cannot supply feed URLs, partner credentials, adapter keys or merchant selection;
- optional batch size remains hard-bounded by M0.21;
- composition and authentication tests;
- architecture documentation.

## Safety invariants
The operations trigger is not authorization to mutate a particular feed. It only starts due-feed discovery. Each discovered source still passes the M0.20 atomic lease and the M0.21 worker path before import.

Provider-specific behavior remains in registered adapters. The production worker has no Daisycon-specific branching beyond adapter registration, so bol.com and later networks can enter through the same contract.
