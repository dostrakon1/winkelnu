## Alignment decisions

1. GitHub is the source of truth for code and project documentation.
2. Winkelnu will be built incrementally rather than generated as a large one-shot application.
3. The storefront architecture remains multi-merchant and feed-driven from the beginning.
4. Next.js App Router + TypeScript + Tailwind remain the intended web stack.
5. Vercel is the intended preview/production deployment platform for the storefront.
6. Persistent catalogue infrastructure is introduced only when the data model milestone requires it.
7. Feed ingestion is treated as a separate subsystem from storefront request rendering.
8. Architectural decisions must be documented before implementation makes them expensive to reverse.
