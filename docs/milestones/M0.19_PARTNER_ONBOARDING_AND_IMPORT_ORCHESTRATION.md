# M0.19 — Partner Onboarding & Import Orchestration

Status: repository-side implemented; CI verification pending.

## Delivered
- explicit onboarding assessment stages;
- preview eligibility and activation eligibility separated;
- preview import quality report;
- default 95% acceptance threshold;
- unresolved product matching blocks preview approval;
- empty previews fail;
- non-destructive preview mode in the existing import pipeline;
- tests proving preview never triggers stale-offer cleanup;
- architecture documentation for activation and recurring-import boundaries.

## Why this matters
A technically reachable partner feed is not automatically production-safe. Winkelnu now has a controlled path between affiliate approval and recurring catalog mutation.

The same import pipeline remains the source of truth for validation and matching. Preview mode changes only destructive stale cleanup; it does not bypass domain validation.

## External gates still pending
- live Supabase project/migrations;
- Daisycon publisher approval and concrete program/feed;
- sanitized real-feed sample mapping validation;
- production scheduler/worker runtime.
