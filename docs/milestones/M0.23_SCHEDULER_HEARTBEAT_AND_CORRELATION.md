# M0.23 — Scheduler Deployment Contract, Heartbeats & Import Run Correlation

Status: repository-side implemented; CI verification pending.

## Delivered
- M0.22 auth nullability regression fixed;
- scheduler-compatible GET/POST operations trigger;
- `CRON_SECRET` support with generic trigger-secret fallback;
- per-trigger correlation ID returned in response/header;
- correlation propagated through production worker/composition;
- `import_runs.correlation_id` persistence for production imports;
- migration `0007_import_heartbeat_and_correlation.sql`;
- service-role-only atomic lease renewal RPC;
- heartbeat control exposed by orchestration service;
- feed pagination emits progress heartbeat after successful page fetch;
- heartbeat writes throttled to avoid one RPC per fast page;
- tests for page heartbeat, heartbeat interval and correlation propagation;
- Supabase activation/setup documentation updated.

## Invariants
- heartbeat cannot revive an already expired lease;
- only the current lease token may renew ownership;
- stale workers cannot renew or complete another worker's run;
- scheduler cadence remains deployment policy, not catalog domain logic;
- storefront availability is independent of worker health;
- one trigger correlation can group several per-feed import runs.
