# M0.50 — Preview Activation Command Sequence & Operator Checklist

Status: repository-side implemented; live execution pending external preview Supabase project.

## Goal
Reduce the first real preview activation to one deterministic operator sequence that links the existing environment contract, migration runbook and evidence pack without weakening any fail-closed gate.

## Delivered
- `docs/operations/PREVIEW_ACTIVATION_COMMAND_SEQUENCE.md`
- explicit Steps 0–10 from frozen activation SHA through evidence-pack closure;
- command gates for repository quality, activation environment, migration manifest/database contract, live Supabase verification, production readiness and project-derived types;
- bounded bootstrap/import, storefront attribution and human operator acceptance steps;
- persistence remains `memory` until all earlier live gates pass;
- emergency stop sequence preserves evidence and returns/keeps preview on memory persistence;
- explicit list of the small set of external Supabase actions Dogan must provide during the real activation session.

## Safety boundary
This milestone does not claim a Supabase project exists, does not apply migrations, does not create users, does not generate live types and does not switch persistence. Those actions require the actual preview environment and must be evidenced in `PREVIEW_ACTIVATION_EVIDENCE_PACK.md`.

## Acceptance
Repository-side M0.50 is complete when:
- the command sequence is committed on `main`;
- the exact latest `main` Quality workflow is green;
- no live activation claim is made without real evidence.
