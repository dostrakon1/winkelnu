# M0.49 — Preview Activation Evidence Pack & Handoff Checklist

Status: repository-side implemented; live preview evidence pending external Supabase project access.

## Goal
Create one canonical, non-secret evidence record for the first real Supabase preview activation so repository readiness, live migration state, security readiness, import evidence and human operator acceptance are never conflated.

## Implemented
- `docs/operations/PREVIEW_ACTIVATION_EVIDENCE_PACK.md`
  - activation identity and exact repository SHA;
  - repository/CI gates;
  - environment preflight;
  - migration state;
  - live connection/security readiness;
  - project-derived database types;
  - catalog/bootstrap/import evidence;
  - storefront and attribution acceptance;
  - human operator acceptance;
  - persistence switch evidence;
  - stop/rollback evidence;
  - final handoff decision.
- All fields that require a real Supabase preview project remain explicitly `PENDING`.
- Secrets, tokens, service-role values and private feed URLs are prohibited from the evidence pack.
- `scripts/verify-preview-evidence-template.mjs` verifies the required sections, safe pending markers and absence of obvious secret assignments.
- `npm run check:preview-evidence-template` is part of the repository `npm run check` chain.

## Safety boundary
This milestone does not claim that migrations have been applied, live RLS has been verified, database types have been generated, imports have run or human operator acceptance has passed. Those remain external/live evidence gates.

## Handoff rule
When preview activation starts, update the evidence pack only with observed results from the actual preview project. Record identifiers and non-secret counts/correlation IDs, never credentials or raw partner/feed payloads.

## Completion gate
Repository-side M0.49 is complete when the evidence pack, verifier and documentation are committed and the exact latest repository Quality run is green. Live preview activation remains pending until a real Supabase preview project exists.

## Next logical phase
M0.50 — Preview Activation Command Sequence & Operator Checklist: prepare the concise command-by-command execution sheet for the real activation session, with explicit user actions versus repository/verifier actions.
