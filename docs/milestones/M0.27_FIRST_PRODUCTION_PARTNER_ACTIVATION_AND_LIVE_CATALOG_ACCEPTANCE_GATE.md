# M0.27 — First Production Partner Activation & Live Catalog Acceptance Gate

Status: repository-side implemented; live partner/Supabase evidence pending.

## Goal

Introduce a formal production activation gate for the first real affiliate partner so that adapter readiness, preview quality, catalog behavior and redirect correctness must all be proven before recurring production import can be enabled.

## First candidate

Daisycon.

This does not mean Daisycon is already live. It means Daisycon is the first partner for which Winkelnu now has a complete acceptance path.

## Delivered

- Generic `PartnerAcceptanceEvidence` contract.
- Fail-closed `assessPartnerProductionActivation` gate.
- Three explicit states: `blocked`, `repository_ready`, `production_approved`.
- Minimum preview acceptance rate of 95% in the production acceptance evidence.
- Zero unresolved match-review requirement for the acceptance gate.
- Catalog visibility, best-offer ranking and freshness evidence requirements.
- Affiliate destination validation using the same HTTPS safety rules as the live redirect service.
- Separate live evidence for Supabase readiness, partner credentials and real-feed preview.
- A real-partner sanitized feed sample is required before `production_approved`.
- Tests proving blocked/repository-ready/production-approved behavior.
- First-partner architecture and operations documentation.

## Truthful current state

The repository can prove the acceptance mechanism and the Daisycon integration architecture, but production approval cannot yet be issued because no live Daisycon feed credential/sample and no live Supabase project connection were supplied in this workspace.

The correct current maximum state is therefore `repository_ready` once the repository-side Daisycon checks pass.

## Production approval requires

1. Actual Daisycon account/program approval.
2. Actual generated product-feed access.
3. Sanitized real feed sample verified against the mapper.
4. Live/preview Supabase migrations and M0.26 security gate passing.
5. Non-destructive preview against the actual feed with >=95% acceptance and zero match reviews.
6. Representative catalog ranking/freshness verification.
7. Affiliate redirect verification.
8. Acceptance gate returns `production_approved`.
